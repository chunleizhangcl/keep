## 1. Fingerprint（指纹）计算详解

### 1.1 什么是 Fingerprint？

Fingerprint（指纹）是 Keep 用于唯一标识告警实例的哈希值。它的核心作用包括：

- **去重（Deduplication）**：识别重复告警，减少告警噪音
- **分组（Grouping）**：将相关告警归类在一起
- **静默（Silencing）**：临时抑制特定指纹的告警
- **可视化（Visualization）**：追踪告警历史和状态

### 1.3 核心代码解析

Fingerprint 的计算逻辑主要在 `keep/providers/base/base_provider.py` 中：

```python
@staticmethod
def get_alert_fingerprint(alert: AlertDto, fingerprint_fields: list = []) -> str:
    """
    计算告警的指纹值
    
    参数:
        alert (AlertDto): 告警对象
        fingerprint_fields (list): 用于计算指纹的字段列表
    
    返回:
        str: 指纹的十六进制字符串
    """
    # 如果没有指定指纹字段，返回告警名称
    if not fingerprint_fields:
        return alert.name
    
    # 创建 SHA256 哈希对象
    fingerprint = hashlib.sha256()
    
    # 将告警转换为字典
    event_dict = alert.dict()
    
    # 遍历每个指纹字段
    for fingerprint_field in fingerprint_fields:
        # 支持嵌套字段访问，如 "labels.host"
        keys = fingerprint_field.split(".")
        fingerprint_field_value = event_dict
        
        # 递归获取嵌套字段值
        for key in keys:
            if isinstance(fingerprint_field_value, dict):
                fingerprint_field_value = fingerprint_field_value.get(key, None)
            else:
                fingerprint_field_value = None
                break
        
        # 处理列表和字典类型的值
        if isinstance(fingerprint_field_value, (list, dict)):
            fingerprint_field_value = json.dumps(fingerprint_field_value)
        
        # 将非空值加入哈希计算
        if fingerprint_field_value is not None:
            fingerprint.update(str(fingerprint_field_value).encode())
    
    return fingerprint.hexdigest()
```

## 2. alert_deduplicator 去重算法详解

### 2.1 去重算法概述

Keep 的去重算法包含两种模式：

1. **部分去重（Partial Deduplication）**：基于指定字段识别相似告警
2. **完全去重（Full Deduplication）**：基于告警全部内容（排除忽略字段）识别重复告警

### 2.4 去重算法核心代码解析

```python
class AlertDeduplicator:
    
    def _apply_deduplication_rule(
        self,
        alert: AlertDto,
        rule: DeduplicationRuleDto,
        last_alert_fingerprint_to_hash: dict[str, str] | None = None,
    ) -> bool:
        """
        应用去重规则到告警
        
        步骤:
        1. 深拷贝告警对象（避免修改原始数据）
        2. 移除需要忽略的字段
        3. 计算告警哈希
        4. 与数据库中相同指纹的上一条告警的哈希进行对比
        5. 设置去重标志
        """
        # 深拷贝，避免修改原始告警
        alert_copy = copy.deepcopy(alert)
        
        # 移除忽略字段（默认忽略 lastReceived）
        for field in rule.ignore_fields:
            alert_copy = self._remove_field(field, alert_copy)
        
        # 计算告警哈希
        # 使用 sort_keys=True 确保字段顺序一致
        alert_hash = hashlib.sha256(
            json.dumps(alert_copy.dict(), default=str, sort_keys=True).encode()
        ).hexdigest()
        alert.alert_hash = alert_hash
        
        # 获取相同指纹的上一条告警的哈希
        last_alerts_hash_by_fingerprint = (
            last_alert_fingerprint_to_hash
            or get_last_alert_hashes_by_fingerprints(
                self.tenant_id, [alert.fingerprint]
            )
        )
        
        # 判断去重类型
        if (last_alerts_hash_by_fingerprint.get(alert.fingerprint)
            and last_alerts_hash_by_fingerprint.get(alert.fingerprint) == alert_hash):
            # 哈希完全相同 -> 完全重复
            alert.isFullDuplicate = True
        elif last_alerts_hash_by_fingerprint.get(alert.fingerprint):
            # 有相同指纹但哈希不同 -> 部分重复
            alert.isPartialDuplicate = True
        # 否则为新告警，不做标记
        
        return alert
```

### 2.5 去重判断逻辑表

| 条件 | isFullDuplicate | isPartialDuplicate | 处理方式 |
|------|-----------------|-------------------|----------|
| 相同 fingerprint + 相同 hash | True | False | 丢弃告警，仅更新 lastReceived |
| 相同 fingerprint + 不同 hash | False | True | 保存告警，关联到同一告警组 |
| 不同 fingerprint | False | False | 保存为新告警 |

## 3. 算法复用指南

### 3.1 算法剥离

Keep 的去重算法可以轻松剥离并在其他项目中使用。以下是一个独立的、可复用的实现：

```python
"""
Keep Alert Deduplication Algorithm - 独立可复用版本

该模块提供了一个通用的告警去重算法，可以在任何 Python 项目中使用。
"""

import copy
import hashlib
import json
from dataclasses import dataclass
from typing import Any, Dict, List, Optional


@dataclass
class Alert:
    """告警数据模型"""
    id: str
    name: str
    fingerprint: Optional[str] = None
    alert_hash: Optional[str] = None
    is_full_duplicate: bool = False
    is_partial_duplicate: bool = False
    data: Dict[str, Any] = None
    
    def __post_init__(self):
        if self.data is None:
            self.data = {}


@dataclass
class DeduplicationRule:
    """去重规则"""
    name: str
    fingerprint_fields: List[str]  # 用于计算 fingerprint 的字段
    ignore_fields: List[str]       # 计算 hash 时忽略的字段
    full_deduplication: bool = True


class AlertDeduplicator:
    """
    告警去重器
    
    使用方法:
        deduplicator = AlertDeduplicator(fingerprint_fields=["service", "error_code"])
        
        # 处理第一个告警
        alert1 = Alert(id="1", name="HighCPU", data={"service": "api", "cpu": 95})
        result1 = deduplicator.process_alert(alert1)
        
        # 处理第二个告警（可能是重复的）
        alert2 = Alert(id="2", name="HighCPU", data={"service": "api", "cpu": 96})
        result2 = deduplicator.process_alert(alert2)
    """
    
    def __init__(
        self,
        fingerprint_fields: List[str] = None,
        ignore_fields: List[str] = None,
    ):
        """
        初始化去重器
        
        Args:
            fingerprint_fields: 用于计算 fingerprint 的字段列表
            ignore_fields: 计算 hash 时忽略的字段列表（默认忽略 timestamp）
        """
        self.fingerprint_fields = fingerprint_fields or []
        self.ignore_fields = ignore_fields or ["timestamp", "lastReceived"]
        
        # 存储历史告警的 hash（按 fingerprint 索引）
        self._hash_store: Dict[str, str] = {}
    
    def calculate_fingerprint(self, alert: Alert) -> str:
        """
        计算告警的指纹
        
        Args:
            alert: 告警对象
            
        Returns:
            指纹的十六进制字符串
        """
        if not self.fingerprint_fields:
            # 没有指定字段时，使用告警名称
            return hashlib.sha256(alert.name.encode()).hexdigest()
        
        fingerprint = hashlib.sha256()
        
        for field in self.fingerprint_fields:
            value = self._get_nested_value(alert.data, field)
            if value is not None:
                if isinstance(value, (list, dict)):
                    value = json.dumps(value, sort_keys=True)
                fingerprint.update(str(value).encode())
        
        return fingerprint.hexdigest()
    
    def calculate_hash(self, alert: Alert) -> str:
        """
        计算告警的完整哈希（用于完全去重）
        
        Args:
            alert: 告警对象
            
        Returns:
            哈希的十六进制字符串
        """
        # 复制数据并移除忽略字段
        data_copy = copy.deepcopy(alert.data)
        for field in self.ignore_fields:
            self._remove_nested_value(data_copy, field)
        
        # 添加基本字段
        hash_data = {
            "name": alert.name,
            "data": data_copy
        }
        
        return hashlib.sha256(
            json.dumps(hash_data, sort_keys=True, default=str).encode()
        ).hexdigest()
    
    def process_alert(self, alert: Alert) -> Alert:
        """
        处理告警并进行去重判断
        
        Args:
            alert: 待处理的告警
            
        Returns:
            处理后的告警（带有去重标志）
        """
        # 计算 fingerprint
        if alert.fingerprint is None:
            alert.fingerprint = self.calculate_fingerprint(alert)
        
        # 计算 hash
        alert.alert_hash = self.calculate_hash(alert)
        
        # 获取相同 fingerprint 的历史 hash
        last_hash = self._hash_store.get(alert.fingerprint)
        
        if last_hash is not None and last_hash == alert.alert_hash:
            # 完全重复
            alert.is_full_duplicate = True
        elif last_hash is not None:
            # 部分重复（相同 fingerprint，不同 hash）
            alert.is_partial_duplicate = True
        
        # 更新 hash 存储
        self._hash_store[alert.fingerprint] = alert.alert_hash
        
        return alert
    
    def _get_nested_value(self, data: Dict, field: str) -> Any:
        """获取嵌套字段的值"""
        keys = field.split(".")
        value = data
        for key in keys:
            if isinstance(value, dict):
                value = value.get(key)
            else:
                return None
        return value
    
    def _remove_nested_value(self, data: Dict, field: str) -> None:
        """移除嵌套字段"""
        keys = field.split(".")
        if len(keys) == 1:
            data.pop(field, None)
        else:
            parent = data
            for key in keys[:-1]:
                if isinstance(parent, dict):
                    parent = parent.get(key, {})
                else:
                    return
            if isinstance(parent, dict):
                parent.pop(keys[-1], None)


# ============== 使用示例 ==============

def example_usage():
    """使用示例"""
    
    # 创建去重器，指定用于计算 fingerprint 的字段
    deduplicator = AlertDeduplicator(
        fingerprint_fields=["service", "error_code"],
        ignore_fields=["timestamp", "cpu_percent"]  # 这些字段的变化不算重复
```

### 3.3 分布式场景扩展

对于分布式系统，可以将 hash 存储替换为 Redis：

```python
import redis
from typing import Optional


class RedisHashStore:
    """Redis 后端的 Hash 存储"""
    
    def __init__(self, redis_url: str = "redis://localhost:6379", ttl: int = 86400):
        self.redis = redis.from_url(redis_url)
        self.ttl = ttl
        self.key_prefix = "alert:hash:"
    
    def get(self, fingerprint: str) -> Optional[str]:
        return self.redis.get(f"{self.key_prefix}{fingerprint}")
    
    def set(self, fingerprint: str, hash_value: str) -> None:
        self.redis.setex(f"{self.key_prefix}{fingerprint}", self.ttl, hash_value)


class DistributedAlertDeduplicator(AlertDeduplicator):
    """支持分布式的告警去重器"""
    
    def __init__(
        self,
        redis_url: str,
        fingerprint_fields: List[str] = None,
        ignore_fields: List[str] = None,
        ttl: int = 86400,
    ):
        super().__init__(fingerprint_fields, ignore_fields)
        self._hash_store = RedisHashStore(redis_url, ttl)
```

### 3.4 关键配置参数

| 参数 | 说明 | 默认值 | 建议 |
|------|------|--------|------|
| `fingerprint_fields` | 计算指纹的字段 | `[]` (使用名称) | 选择能唯一标识告警类型的字段 |
| `ignore_fields` | 忽略的字段 | `["lastReceived"]` | 添加时间戳、计数器等变化字段 |
| `ttl` (Redis) | Hash 缓存过期时间 | 86400秒 | 根据告警生命周期调整 |

### 3.5 最佳实践

1. **选择合适的 fingerprint_fields**
   - 选择能够唯一标识告警"类型"的字段
   - 避免选择经常变化的字段
   - 示例：`["service", "alert_name", "host"]`

2. **合理配置 ignore_fields**
   - 忽略时间戳相关字段
   - 忽略计数器、统计值等
   - 示例：`["timestamp", "count", "cpu_percent"]`

3. **存储后端选择**
   - 单机：使用内存字典
   - 多实例：使用 Redis
   - 需要持久化：使用数据库

4. **性能优化**
   - 批量处理告警
   - 使用连接池
   - 合理设置缓存 TTL

## 总结

Keep 的告警去重算法是一个两阶段的设计：

1. **Fingerprint 阶段**：通过 Provider 定义的字段计算告警的唯一标识，用于将相同类型的告警归为一组。

2. **Deduplication 阶段**：在同一 fingerprint 组内，通过完整 hash 比较判断告警是完全重复还是部分重复。

这种设计的优势：
- **灵活性**：可以针对不同 Provider 定制指纹计算规则
- **准确性**：两阶段比较减少误判
- **可扩展**：易于添加新的去重规则
- **高性能**：使用 SHA256 哈希确保比较效率

通过上述剥离的代码，您可以轻松地在自己的项目中实现类似的告警去重功能。
