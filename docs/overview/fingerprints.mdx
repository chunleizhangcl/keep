<Warning>
  如果 provider 未声明指纹字段，指纹默认使用告警名称。
</Warning>

在 Keep 的告警场景中，指纹具有以下重要作用：

### 去重

告警指纹用于避免对同一根本告警重复触发富化/工作流。
当 Keep 接收到告警时，会基于 provider 中声明的字段计算指纹。
如果两条告警具有相同指纹，Keep 会认为它们是重复告警并仅保留其中一条。
这有助于降低告警噪音并避免不必要的工作流触发/富化。

### 分组

Keep 使用告警指纹将相关告警进行分组。
具有相同指纹的告警会被视为同一组，意味着它们由相同的底层条件或问题触发。
告警分组可以帮助运维人员理解不同告警来源之间的关系、定位根因，并更快采取行动。

### 静默

告警指纹可用于第三方工具中的静默/屏蔽。
静默允许运维人员临时抑制具有特定指纹的告警，从而在已知问题期间避免产生额外通知/触发。

### 可视化

告警指纹也可用于可视化与分析。
它们有助于跟踪告警随时间的历史与状态，并将告警与特定条件或系统变化进行关联。

指纹的生成过程是对 provider 中配置的字段及其在告警实例上的取值进行哈希。
最终得到一个固定长度的十六进制字符串，用于唯一标识该告警。
Keep 在接收/获取告警时，会为每条告警计算指纹，以判断是否触发工作流、参与分组或被静默。

总之，Keep 的告警指纹是管理与组织各类第三方系统告警的关键机制。
它能防止重复告警、实现分组、支持静默，并为分析与可视化提供基础，帮助更高效地运营与维护被监控系统。

### Keep 如何计算指纹

Keep 以两层方式设置 `alert.fingerprint`（优先 provider/自定义规则，其次回退逻辑）：

1. **Provider/自定义规则计算**：每个 provider 可以声明 `FINGERPRINT_FIELDS`。在格式化告警时，`BaseProvider.get_alert_fingerprint()` 按顺序遍历这些字段，逐层访问嵌套键（如 `labels.instance`），对 list/dict 值进行 JSON 序列化，并将每个值（以 UTF-8 字节）输入 SHA-256 哈希。生成的十六进制摘要即为指纹。如果字段列表为空，则返回 `alert.name`。
2. **告警回退**：如果 provider 未设置指纹，`AlertDto` 校验器（`get_fingerprint`）会对 `alert.name` 进行哈希（若 `name` 缺失则对完整 payload 哈希）。如果在模型创建时提供了指纹字符串，则会截断为 255 个字符。
3. **自定义去重规则**：当自定义规则定义了 `fingerprint_fields` 时，Keep 会在 provider 格式化告警后使用这些字段重新计算指纹。

```text
Provider 事件
   │
   ├─ format -> AlertDto(name, ...)
   ├─ fingerprint_fields = FINGERPRINT_FIELDS or 自定义规则
   ├─ BaseProvider.get_alert_fingerprint()
   │     ├─ 按顺序提取嵌套字段
   │     ├─ json.dumps(list/dict values)
   │     └─ SHA-256 -> hexdigest
   └─ 如果创建时 fingerprint 仍为 None:
         AlertDto.get_fingerprint(name 或 payload) -> SHA-256
```

### 示例

这是 base provider 类中指纹字段的定义：

```python base_provider.py
class BaseProvider(metaclass=abc.ABCMeta):
    OAUTH2_URL = None
    PROVIDER_SCOPES: list[ProviderScope] = []
    PROVIDER_METHODS: list[ProviderMethod] = []
    FINGERPRINT_FIELDS: list[str] = []
```

这是 Datadog provider 的指纹字段实现示例，我们基于事件的 groups 与 monitor id 计算指纹：

```python datadog_provider.py
class DatadogProvider(BaseProvider):
    """
    Datadog provider class.
    """

    PROVIDER_SCOPES = [
      ...
    ]
    PROVIDER_METHODS = [
      ...
    ]
    FINGERPRINT_FIELDS = ["groups", "monitor_id"]
```

  Keep 支持对指纹相关的行为进行定制。如果你想修改某个 provider 的指纹计算方式，只需配置所需的字段即可。
</Card>
